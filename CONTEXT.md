# Personal site

The shared place for the Tools Craig builds for family and friends. Its public Landing page welcomes Visitors; signing in gives Members a different experience showing only the Tools they can access.

## Language

### Site

**Landing page**:
The public front page, framed as "Welcome to The Lobby". It introduces the shared place rather than presenting a catalog of Tools.
_Avoid_: Portfolio, home page

**The VIP Lobby**:
Craig's proposed name for the signed-in experience, which shows only the Tools a Member has access to. The name awaits confirmation in the design brief.

**Tool**:
Anything the site offers for someone to use.
_Avoid_: App, project

**Visitor**:
Anyone using the site without being signed in.

**Member**:
A person the Owner has invited to at least one Tool. Access is granted per Tool.
_Avoid_: User, account

**Owner**:
Craig, the only person who invites Members and grants access to Tools.
_Avoid_: Admin

**Sign-in session**:
The stretch of time during which the site keeps recognising a Member after they sign in.
_Avoid_: Session (on its own), login

### Soccer

**Schedule Downloader**:
The Tool that puts a Team's schedule in a person's calendar. It exists because the league offers no way to do this; it is unofficial and not affiliated with the league.

**Facility**:
A league venue where games are played. Every Team plays at one Facility.
_Avoid_: Location, site

**Session**:
One run of league play, after which the league issues every Team a new Team ID.
_Avoid_: Season

**Team**:
A group of players that keeps its name from Session to Session.

**Team ID**:
The number the league gives a Team for one Session. The same Team has a different Team ID in the next Session.

**Remembered team**:
A Team a Member has saved, so the Member can get its schedule each Session without looking up the new Team ID.

**Session link**:
A calendar address for the Teams someone has chosen, good for one Session. Anyone who has it can use it.

**Member link**:
A Member's secret calendar address, which follows their Remembered teams from Session to Session. The Member can replace it.

**Connected calendar**:
The Google calendar a Member has picked for the site to keep current with their Remembered teams' games and scores.
_Avoid_: Sync

### Minecraft

**World**:
A Minecraft game environment: its blocks, terrain and saved data.
_Avoid_: Server (when referring to the game environment)

**Server**:
The running Minecraft software that players connect to.
_Avoid_: Machine, host

**Machine**:
The computer a Server runs on.
_Avoid_: Server (when referring to the computer)
